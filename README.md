# CI/CD Pipeline with Jenkins, Git, and Docker

## Overview
This project demonstrates my skills in **Jenkins**, **CI/CD concepts**, **Git**, and **Docker** by setting up an automated pipeline for building, testing, and deploying applications. It integrates Jenkins with Git for version control and Docker for containerization.

## Features
- **Continuous Integration (CI):** Automatically build and test code on every Git commit.
- **Continuous Deployment (CD):** Deploy Dockerized applications using Jenkins pipelines.
- **Docker Integration:** Builds and pushes Docker images to a registry.
- **Git Integration:** Automates code retrieval and version tracking.
